# Задание 1

## Задача 1.3. Имена

### Условие

Создать сущность `Имя`, которая описывается тремя параметрами:

- Фамилия;
- Личное имя;
- Отчество.

Имя должно приводиться к строковому виду:

```
Фамилия Имя Отчество
```

Если какой-либо параметр отсутствует, он не должен участвовать в формировании строки.

### Реализация

Был создан класс `Name`, содержащий поля:

- `surname` — фамилия;
- `firstName` — личное имя;
- `patronymic` — отчество.

Созданы следующие объекты:

```
Клеопатра

Пушкин Александр Сергеевич

Маяковский Владимир
```

Для вывода информации был переопределён метод `toString()`.

### Результат

Программа корректно выводит имена, учитывая только заданные параметры.

# Задание 2

## Задача 2.2. Человек с именем

### Условие

Объединить сущности `Человек` и `Имя`, чтобы имя человека задавалось объектом класса `Name`, а не строкой.

### Реализация

Создан класс `Human`, который содержит:

- объект класса `Name`;
- рост человека.

Созданы объекты:

```
Клеопатра, рост: 152

Пушкин Александр Сергеевич, рост: 167

Маяковский Владимир, рост: 189
```

Для вывода информации используется метод `toString()`.

### Алгоритм решения

1. Создан класс `Human`.
2. Добавлено поле типа `Name`.
3. Создан конструктор для задания имени и роста.
4. Реализован вывод объекта в строковом виде.

## Задача 2.3. Человек с родителем

### Условие

Дополнить сущность `Человек` возможностью задавать отца, который также является объектом класса `Human`.

При выводе необходимо учитывать:

- фамилию отца;
- отчество, созданное от имени отца.

### Реализация

Добавлено поле:

```
Human father
```

Созданы объекты:

```
Чудов Иван

Чудов Петр

Чудов Борис
```

Связь между объектами:

```
Иван является отцом Петра

Петр является отцом Бориса
```

### Алгоритм решения

1. В класс `Human` добавлено поле родителя.
2. Создан новый конструктор с параметром отца.
3. При выводе проверяется наличие фамилии и отчества.
4. При отсутствии данных используются данные родителя.

# Задание 5

## Задача 5.2. Кот мяукает

### Условие

Создать сущность `Кот`.

Кот должен иметь:

- имя;
- возможность мяукать;
- возможность мяукать несколько раз.

### Реализация

Создан класс `Cat`.

Создан объект:

```
Барсик
```

Реализованы методы:

```java
meow()
```

и

```java
meow(int n)
```

### Результат

Одно мяуканье:

```
Барсик: мяу!
```

Мяуканье три раза:

```
Барсик: мяу-мяу-мяу!
```

### Алгоритм решения

1. Создан класс `Cat`.
2. Добавлено поле имени.
3. Создан метод для одного мяуканья.
4. Создан метод для повторения мяуканья.
5. Переопределён метод `toString()`.
